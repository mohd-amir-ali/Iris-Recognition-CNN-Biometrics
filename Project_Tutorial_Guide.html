SECTION 01 - END-TO-END BIOMETRIC PIPELINE

How the Whole Iris Recognition Project Works

The human iris contains over 240 unique trabecular degrees of freedom (crypts, radial furrows, and collarette rings) that remain stable throughout a person's life. Your project identifies individuals across 108 subjects (683 Near-Infrared eye scans from the CASIA-IrisV1 dataset) through a 4-stage computer vision and deep learning pipeline:

[Raw 850nm NIR Eye Scan (CASIA1 / testSamples)] │ Stage 1: Grayscale Read (cv2.imread) + 5×5 Median Blur (cv2.medianBlur) ▼ [Hough Circle Transform & Bitwise Masking (getIrisFeatures)] │ Stage 2: Detects circular pupil & iris boundary (cv2.HoughCircles) │ Crops isolated circular iris ROI -> saves to test.png (64×64×3) ▼ [7-Layer Deep Sequential CNN (model.json + model_weights.h5)] │ Stage 3: Conv2D(32, 3×3) → MaxPool(2×2) → Conv2D(32, 3×3) → MaxPool(2×2) │ → Flatten(6,272) → Dense(256, ReLU) → Softmax(108 Classes) ▼ [Live Optical Scan Modal Popup & Identity Match] └──► Stage 4: Outputs Predicted Person ID (#001-#108), Confidence %, & Liveness Check
STAGE 01

NIR Acquisition & Denoising

Loads the eye image in grayscale and applies a 5×5 median filter (cv2.medianBlur(img, 5)) to suppress eyelash and specular reflections.

STAGE 02

Hough Circle Segmentation

Runs cv2.HoughCircles (param1=63, param2=70) to lock onto the circular iris boundary, masks out the sclera/eyelids via cv2.bitwise_and, and crops test.png.

STAGE 03

7-Layer CNN Forward Pass

Resizes the segmented iris to 64×64×3, normalizes pixel intensities to [0, 1], and passes the tensor through 1,643,788 trained parameters.

STAGE 04

Softmax Match & Spoof Check

Computes argmax(preds) + 1 across all 108 subjects, displays the live scan modal popup, and checks corneal reflection liveness to block printed spoof attacks.

SECTION 03 - CUSTOMIZATION TUTORIAL

Where to Make Frontend & Backend Edits

1. Changing Colors or Bento Card Styling

Open static/iris_style.css (lines 3-25) or the top <style> block inside index.html / Launch_Iris_Dashboard.html:

:root { --bg-primary: #F5F2EB; /* Warm Alabaster page background */ --ocular-dark: #0E131B; /* Dark Ophthalmoscope viewport background */ --accent-indigo: #D97706; /* Golden Iris Amber primary accent */ --accent-cyan: #0D9488; /* Biometric Laser Teal secondary accent */ --radius-bento: 18px; /* Rounded corner radius of Bento cards */ }

2. Adjusting Full-Window Gaze Tracking & Blink Frequency

Inside index.html (in the initGazeTrackingEyeScanner() function), you can tweak the iris radius, vertical eyelid opening, or how far the pupil moves across the browser window:

const eyeHalfW = 152; // Horizontal width of the stationary eyelid contour const baseEyeOpenH = 92;// Vertical eyelid opening height const irisR = 66; // Radius of the moving iris disc targetGazeX = Math.cos(angle) * Math.pow(clampFactor, 0.78) * 42; // Window-wide horizontal travel targetGazeY = Math.sin(angle) * Math.pow(clampFactor, 0.78) * 21; // Window-wide vertical travel

3. Editing the Live Scan Popup Modal Speed or Text

Inside index.html (in the openLiveScanModal() function), the scan animation increments progress += 4 every 48ms (taking ~1.2 seconds total). Change 48 to a smaller number for a faster scan or a larger number for a slower, more dramatic scan.
